# THEATRON 2026 🎭

A wide cinematic theatre & cinema experience landing application built with **Next.js 14** and **React 18** for Chennai Institute of Technology (CIT), presented in collaboration with **IMMERSE × Team Resolution**.

---

## 🌟 The Experience

1. **Direct Video Start (8K Ultra HD)**:
   - Starts directly with the camera moving down the dark auditorium aisle towards the stage.
   - All Gemini watermarks cleanly removed across all frames.
   - Mild, atmospheric theatre room tone.
2. **Curtains Opening Transition**:
   - As the velvet curtains part at the stage, an anamorphic lens flare sweeps across the screen and smoothly dissolves directly into the continuous theatrical stage interface.
3. **Continuous Theatrical Stage Composition**:
   - Wide cinematic composition ($100\text{vw} \times 100\text{vh}$).
   - **Visual Hierarchy**: Stage / Performance (Right & Center) $\rightarrow$ THEATRON branding (Left) $\rightarrow$ Event Information $\rightarrow$ Actions.
   - Clean background without baked-in duplicates.
   - Real-time live countdown timer to the festival.
   - Interactive **Theatrical Playbill** drawer for events (Stage Play, Short Film, Monologue Clash, Street Theatre).
   - Widescreen 8K cinema trailer projection player.
   - Download links for both polished 8K UHD videos.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Next.js Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
